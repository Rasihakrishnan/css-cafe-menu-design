# ☕ Responsive Cafe Menu – HTML & CSS

A clean and modern cafe menu designed using pure HTML5 and CSS3.  
This project focuses on layout design, typography, spacing, and responsive styling.

## 🚀 Project Overview

This cafe menu web page displays different food and beverage items with pricing in a structured and visually appealing format. The goal of this project was to practice CSS styling fundamentals including:

- Box Model
- Typography
- Color Styling
- Layout Alignment
- Responsive Design Basics

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox (if used)
- Responsive Units (rem, %, etc.)

## 📌 Features

- Clean and minimal UI
- Proper spacing and alignment
- Organized menu sections
- Mobile-friendly layout
- Structured semantic HTML

## 🎯 What I Learned

- How CSS controls layout and spacing
- Difference between margin and padding
- Using classes effectively
- Creating visually balanced UI designs
